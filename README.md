# Detective Quest - Tema 4

Sistema de investigação de casos para detetives.

## Funcionalidades

- Listar casos em aberto
- Adicionar novos casos
- Interface simples e intuitiva

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Adicione novos casos usando o campo de texto
3. Visualize a lista de casos atualizada

## Tecnologias

- HTML
- CSS  
- JavaScript
